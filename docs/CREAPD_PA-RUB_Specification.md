# CREAPD PA-RUB Specification

## Constitution-Level Quality Assurance Specification

This document contains the canonical implementation specifications for all 8 Presentation Asset Rubrics (PA-RUB-001 through PA-RUB-008).

### Rubric Index

| ID | Name | Applies To |
|---|---|---|
| PA-RUB-001 | Master Presentation Asset Rubric | All Presentation Assets |
| PA-RUB-002 | Presentation Point Rubric | Presentation Points |
| PA-RUB-003 | StorySlide Rubric | StorySlides |
| PA-RUB-004 | Script Rubric | All Presentation Scripts |
| PA-RUB-005 | Image Rubric | Generated Images, Illustrations, Graphics |
| PA-RUB-006 | Voice Rubric | Voiceovers, Narration, Speech Synthesis |
| PA-RUB-007 | Video Rubric | Generated Videos, Motion Graphics, B-Roll |
| PA-RUB-008 | Layout Rubric | StorySlide Layouts, Presentation Templates |

### Universal Evaluation Pipeline

Every asset follows: Generate → Master Rubric → Asset-Specific Rubric → Quality Score → Pass/Revise/Escalate

### Quality Levels

- Draft (75+)
- Standard (85+)
- Professional (92+)
- Broadcast Ready (97+)

### Review Actions

- **PASS**: Asset advances to next stage
- **REVISE**: Worker receives quality report, failed criteria, recommendations
- **ESCALATE**: Repeated failures or low confidence → Controller review
- **PRODUCER REVIEW**: Subjective judgment required

### Revision Limits

- Default maximum: 5 iterations
- After maximum reached, CREAPr notifies the producer
