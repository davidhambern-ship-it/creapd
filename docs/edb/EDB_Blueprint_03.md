# News Production Environment Design Blueprint

## Blueprint 3 — Research Department

### 1. Environment Purpose

The Research Department is the investigative heart of News Production. Contains Research Desk, Sources, Import URL. Focuses on discovering, validating, organizing, and enriching information before it becomes part of a story package. Should feel like a modern investigative journalism department.

### 2. Experience Goal

Understand: what's being researched, which sources are trustworthy, what evidence has been collected, what needs verification, what research is ready for production. Feel like an investigative journalist with an entire research staff.

### 3. Floor Plan

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                     LIVE SOURCE MONITOR WALL                               │
├─────────────────────────────────────────────────────────────────────────────┤
│ Source Intelligence        Evidence Board        AI Research Assistant       │
│ Citation Library           Research Desk         Import Station              │
│ Verification Table         Active Research       Source Archive              │
└─────────────────────────────────────────────────────────────────────────────┘
```

The Research Desk is the Hero Asset.

### 4. Primary PEAL Assets

**Research Desk** — Active investigation, research packets, open citations, working notes, current project, AI collaboration.

**Source Intelligence Wall** — Source catalog, credibility indicators, publisher information, RSS feeds, recently used sources, trusted source collections, source categories.

**Import Station** — Import articles, PDFs, videos, RSS feeds, websites, documents, transcripts. Resembles a digital intake station.

**Evidence Board** — Related research, connected stories, timeline, supporting/contradicting evidence, open questions. Visually connected.

**AI Research Assistant** — Suggests additional sources, verifies claims, finds related stories, detects duplicates, builds summaries, recommends citations.

**Verification Table** — Fact checking, source comparison, citation validation, confidence scoring, conflict detection.

**Source Archive** — Previously imported material, archived investigations, historical research, saved source collections.

### 5-12. Standard Sections

Page Mapping: Research Desk → central investigation workspace; Sources → Source Intelligence Wall; Import URL → Import Station. Integrates Foundation Seeder, SMC, Handler Registry. Research naturally flows into Story Folders.

### 13. Acceptance Tests

- ✓ Research feels like an investigative department.
- ✓ Sources become an intelligence wall rather than a data table.
- ✓ Import URL becomes a digital intake station.
- ✓ Foundation Seeder visibly powers incoming research.
- ✓ SMC processing feels integrated into the environment.
- ✓ Research naturally flows into Story Folders.
- ✓ AI behaves like a research partner.
- ✓ Existing functionality remains intact.

### Final Rule

Do not build a search page. Build the department responsible for discovering truth.
