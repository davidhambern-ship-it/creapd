# News Production Environment Design Blueprint

## Blueprint 2 — Editorial Planning Office

### 1. Environment Purpose

The Editorial Planning Office is where producers plan broadcasts before production begins. Contains Weekly Planner. Quiet, strategic, and forward-looking. This is where the producer decides what will be covered, when, and why it matters.

### 2. Experience Goal

Understand: this week's content schedule, upcoming events, story priorities, production deadlines, available production capacity. Feel like an Executive Producer planning an entire network.

### 3. Floor Plan

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    NETWORK CALENDAR DISPLAY                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│ Editorial Calendar        Weekly Planning Board       AI Planning Assistant  │
│ Event Timeline            Executive Planning Desk     Upcoming Productions   │
│ Long-Term Planning        Production Schedule         Completed Weeks        │
└─────────────────────────────────────────────────────────────────────────────┘
```

The Executive Planning Desk is the Hero Asset.

### 4. Primary PEAL Assets

**Executive Planning Desk** — Displays current week, shows production priorities, opens planning sessions, displays producer notes, shows planning progress.

**Weekly Planning Board** — Drag-and-drop scheduling, story assignments, daily themes, production deadlines, broadcast planning.

**Network Calendar Display** — Weekly view, monthly overview, major events, holidays, elections, sporting events, seasonal reminders.

**Event Timeline** — Upcoming news events, scheduled interviews, planned broadcasts, deadlines, campaigns, special productions.

**AI Planning Assistant** — Suggests story distribution, warns of scheduling conflicts, recommends topic balance, identifies slow news days, suggests evergreen content.

**Upcoming Productions** — Stories in production, upcoming broadcasts, pending exports, scheduled releases.

### 5-12. Standard Sections

Page Mapping: Weekly Planner → Planning Board + Calendar Display + Event Timeline + Executive Desk. Camera positions: Overview, Executive Desk, Planning Board, Calendar Display, Timeline, AI Assistant. Implementation: replace Weekly Planner page with environmental workspaces, bind existing planner data, smooth camera transitions.

### 13. Acceptance Tests

- ✓ Weekly Planner feels like an executive planning office.
- ✓ Planning Board replaces generic scheduling grids.
- ✓ Calendar Display remains easily readable.
- ✓ AI Planning Assistant feels like another producer.
- ✓ Navigation remains environmental.
- ✓ Existing planning functionality remains intact.

### Final Rule

Do not build a scheduling page. Build the planning office where the executive producer prepares the network's week.
