# News Production Environment Design Blueprint (EDB)

**EDB Version 1.0 Complete**

The EDB suite defines how the News Production profile's pages are transformed from generic dashboards into immersive environmental workspaces. Each blueprint maps existing pages to PEAL environmental assets arranged as a physical room.

> **Final Rule:** Do not build a dashboard that looks like a newsroom. Build a newsroom whose objects perform the work of the dashboard. The set design is the UI.
