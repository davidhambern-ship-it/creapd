# News Production Environment Design Blueprint

## Blueprint 4 — Broadcast Control Room

### 1. Environment Purpose

The Broadcast Control Room is where stories stop being ideas and become finished broadcasts. Contains Production, Export Center. Where producers assemble complete programs, preview broadcasts, render assets, and publish finished productions.

### 2. Experience Goal

Understand: which productions are in progress, which segments are complete, which assets are missing, which broadcasts are ready for export, which have been published. Feel like the Executive Producer moments before a national broadcast goes live.

### 3. Floor Plan

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                     PROGRAM STATUS DISPLAY                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│ Broadcast Monitor Wall      Live Rundown Display      AI Production Director │
│ Segment Assembly Desk       Production Console        Preview Theater        │
│ Export Center               Distribution Board        Production Archive      │
└──────────────────────────────────────────────────────────────────────────────┘
```

The Production Console is the Hero Asset.

### 4. Primary PEAL Assets

**Production Console** — Assemble show, arrange rundown, control production workflow, review status, trigger rendering, prepare broadcast.

**Segment Assembly Desk** — Displays completed Story Folders, arrange segment order, remove/duplicate segments, insert transitions, attach graphics/media.

**Live Rundown Display** — Current running order, segment timing, total runtime, missing assets, segment readiness, air order. Always visible.

**Broadcast Monitor Wall** — Program preview, graphics preview, audio status, caption status, broadcast health, export progress.

**Preview Theater** — Preview complete show, preview selected segment, review transitions/graphics/captions/timing.

**Export Center** — Export to video, PDF, script, teleprompter, social media, archive.

**AI Production Director** — Detect missing assets, suggest segment order, improve pacing, recommend transitions, detect issues, verify package completeness.

**Distribution Board** — Publication destinations, scheduled releases, completed exports, distribution history, platform status.

### 5-12. Standard Sections

Page Mapping: Production → Production Console + Segment Assembly Desk + Live Rundown + Preview Theater + Broadcast Monitor Wall; Export Center → Export Center + Distribution Board. Story Folders connect directly from Newsroom Floor into Segment Assembly Desk.

### 13. Acceptance Tests

- ✓ Production feels like assembling a professional broadcast.
- ✓ Story Folders become production segments.
- ✓ Live Rundown is always visible.
- ✓ Preview Theater feels like screening a real program.
- ✓ Export Center feels like launching a completed production.
- ✓ AI Production Director behaves like a trusted technical director.
- ✓ Existing functionality remains intact.

### Final Rule

Do not build an export page. Build the room where broadcasts come together.
