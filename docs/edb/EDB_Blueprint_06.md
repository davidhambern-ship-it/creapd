# News Production Environment Design Blueprint

## Blueprint 6 — Archive & Operations Department

### 1. Environment Purpose

The Archive & Operations Department is the administrative and operational backbone of News Production. Contains Story Library, Archive, Automation, Organizations, Activity Center, Security & Privacy, My Profile, Settings.

### 2. Experience Goal

Understand: what has been produced, what automations are running, what organizational resources exist, what activity has occurred, how Producer is configured, system health. Feel like a Network Operations Director overseeing the entire organization.

### 3. Floor Plan

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                     NETWORK STATUS DISPLAY                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│ Archive Library          Automation Center       Activity Command             │
│ Operations Desk          Organization Board      Security Center              │
│ Settings Workshop        Personal Office         Historical Archive           │
└──────────────────────────────────────────────────────────────────────────────┘
```

The Operations Desk is the Hero Asset.

### 4. Primary PEAL Assets

**Operations Desk** — Overall system health, producer status, organization overview, current automation summary, recent activity, operational shortcuts.

**Archive Library** — Browse completed productions, search stories, restore archived projects, filter by category, timeline view, historical production records.

**Automation Center** — View/create/pause automations, review completed tasks, automation history, AI workflow monitoring. Mission control for automation.

**Activity Command** — Recent activity, AI actions, user actions, publishing history, team activity, notifications.

**Organization Board** — Organizations, teams, departments, permissions, workspace management.

**Security Center** — Authentication, privacy controls, API keys, permissions, connected services, security audits.

**Personal Office** — Producer profile, personal preferences, saved workspaces, favorite templates, recent activity, personal achievements.

**Settings Workshop** — Application preferences, appearance, notifications, integrations, production defaults, system configuration.

### 5-12. Standard Sections

Page Mapping: Story Library + Archive → Archive Library; Automation → Automation Center; Organizations → Organization Board; Activity Center → Activity Command; Security & Privacy → Security Center; My Profile → Personal Office; Settings → Settings Workshop. All departments connect: Newsroom → Planning → Research → Production → Creative Services → Archive & Operations.

### 13. Acceptance Tests

- ✓ Story Library feels like a professional archive.
- ✓ Automation feels like mission control.
- ✓ Organizations resemble a real organizational command board.
- ✓ Security feels like a secure operations office.
- ✓ Settings feel like configuring a broadcast network.
- ✓ Personal Office feels personalized and welcoming.
- ✓ Existing functionality remains intact.
- ✓ Every News Production department feels connected.

### Final Rule

Do not build an administration dashboard. Build the operational headquarters that keeps an entire broadcast network running.
