# News Production Environment Design Blueprint

## Blueprint 5 — Creative Services Department

### 1. Environment Purpose

The Creative Services Department is where the visual identity of the broadcast network is created, managed, and maintained. Contains Brand Profiles, Show Profiles, Templates, Graphics Templates, Prompt Templates, Image/Video Library.

### 2. Experience Goal

Understand: which brands are available, which shows exist, which templates are approved, which creative assets are ready, which AI creative tools are available. Feel like an Art Director alongside a world-class creative team.

### 3. Floor Plan

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                     NETWORK BRAND GALLERY                                   │
├──────────────────────────────────────────────────────────────────────────────┤
│ Brand Gallery            Show Gallery          AI Creative Director           │
│ Creative Worktable       Template Wall         Graphics Studio               │
│ Prompt Lab               Media Library         Asset Vault                   │
└──────────────────────────────────────────────────────────────────────────────┘
```

The Creative Worktable is the Hero Asset.

### 4. Primary PEAL Assets

**Creative Worktable** — Current creative project, active brand, current show, recent templates, recently generated assets, quick creative actions.

**Brand Gallery** — Browse brands, open brand identities, guidelines, logos, colors, typography, approved visual language.

**Show Gallery** — Browse shows, open show packages, intro graphics, lower thirds, music packages, branding kits.

**Template Wall** — Browse/preview/duplicate/favorite/apply templates, categorize. Resembles a designer's inspiration board.

**Prompt Lab** — Prompt library, categories, AI prompt builder, saved prompt packs, prompt testing.

**Graphics Studio** — Generate/edit/review/organize graphics, version history.

**Media Library** — Browse images/video/audio, upload media, AI-generated assets, favorite collections.

**AI Creative Director** — Recommend layouts, suggest branding, generate ideas, improve prompts, maintain consistency, detect brand conflicts.

### 5-12. Standard Sections

Page Mapping: Brand Profiles → Brand Gallery; Show Profiles → Show Gallery; Templates + Graphics Templates → Template Wall + Graphics Studio; Prompt Templates → Prompt Lab; Image/Video Library → Media Library. Every asset immediately available to Newsroom Floor and Broadcast Control Room.

### 13. Acceptance Tests

- ✓ Brand Profiles feel like a Brand Gallery.
- ✓ Show Profiles feel like a production showcase.
- ✓ Templates feel like a designer's inspiration wall.
- ✓ Prompt Templates feel like a creative writing lab.
- ✓ Media Library feels like a professional asset archive.
- ✓ AI behaves like a Creative Director.
- ✓ Existing functionality remains intact.

### Final Rule

Do not build a page full of folders and thumbnails. Build the creative department of a world-class broadcast organization.

**End of Blueprint 5 — Creative Services Department**
