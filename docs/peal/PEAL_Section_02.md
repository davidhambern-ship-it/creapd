## Section 2 — Asset Taxonomy, Object Categories & Generic UI Replacement Map

### Primary Instruction

PEAL assets should be organized into logical categories.

These categories should remain consistent across every Production Profile.

Every asset belongs to exactly one primary category, but may be used in multiple environments.

The purpose of the taxonomy is to ensure Producer develops one unified environmental language rather than disconnected interface styles.

### PEAL Asset Taxonomy

PEAL assets are organized into the following categories.

#### Category 1 — Structural Assets

Structural Assets define the physical environment.

These assets create the room itself.

Examples:

- Walls
- Floors
- Ceilings
- Windows
- Doors
- Columns
- Room Dividers
- Lighting Fixtures
- Display Niches

These assets establish atmosphere but generally do not perform workflow actions.

#### Category 2 — Workspace Assets

Workspace Assets are where the producer performs work.

These are the primary interaction surfaces.

Examples:

- Producer Desk
- Study Desk
- Research Table
- Broadcast Desk
- Drafting Table
- Editing Station
- Workbench

Every environment should contain one Primary Workspace Asset.

#### Category 3 — Information Display Assets

Display Assets present information.

These replace traditional dashboards.

Examples:

- Broadcast Monitor
- Monitor Wall
- LED Ticker
- Digital Status Display
- Production Screen
- Weather Display
- Market Board
- Sports Board
- Analytics Screen
- World Map Display

Display Assets should always communicate live or meaningful information.

#### Category 4 — Planning Assets

Planning Assets organize work.

Examples:

- Whiteboard
- Assignment Board
- Rundown Board
- Glass Board
- Editorial Board
- Planning Wall
- Kanban Board
- Timeline Wall

Planning Assets replace lists, tables, and planning dashboards.

#### Category 5 — Storage Assets

Storage Assets organize permanent information.

Examples:

- File Cabinet
- Archive Shelf
- Bookshelf
- Media Cabinet
- Asset Locker
- Equipment Rack
- Reference Shelf

Storage Assets replace navigation trees, archives, and long lists.

#### Category 6 — Information Objects

Information Objects contain individual pieces of work.

Examples:

- Story Folder
- Research Folder
- Clipboard
- Notebook
- Binder
- Script
- Book
- Magazine
- Report
- Production Packet

These objects usually represent a single project or record.

#### Category 7 — Temporary Information Assets

Temporary Assets represent work that is still in progress.

Examples:

- Sticky Notes
- Draft Pages
- Cue Cards
- Index Cards
- Research Notes
- Alerts
- Flags
- Temporary Markers

These assets naturally appear and disappear as work evolves.

#### Category 8 — Control Assets

Control Assets execute actions.

Examples:

- Broadcast Console
- Control Panel
- Switchboard
- Mixing Console
- Production Controls
- Equipment Controls

These replace generic toolbars and action bars.

#### Category 9 — AI Assets

AI Assets represent Producer's digital teammates.

Examples:

- AI Producer Booth
- AI Research Terminal
- AI Assistant Display
- AI Notification Board
- AI Activity Display

AI should feel embedded within the environment rather than floating outside it.

#### Category 10 — Navigation Assets

Navigation Assets help producers move through environments.

Examples:

- Directory Wall
- Department Signage
- Elevator Panel
- Hallway Display
- Room Directory
- Floor Map

Navigation should feel architectural rather than web-based.

#### Category 11 — Ambient Assets

Ambient Assets create immersion.

Examples:

- Clock
- Plants
- Windows
- Skyline
- Lighting
- Awards
- Cameras
- Studio Equipment
- Decorative Maps

Ambient Assets should support storytelling.

They should never distract from workflow.

### Generic UI Replacement Map

Producer should prefer environmental assets over traditional web components whenever practical.

#### Navigation Sidebar

Replace with:

- File Cabinet
- Wall Directory
- Department Directory
- Bookshelf
- Equipment Rack

#### Dashboard

Replace with:

- Monitor Wall
- Operations Display
- Status Board
- Broadcast Displays

#### Card

Replace with:

- Folder
- Clipboard
- Notebook
- Sticky Note
- Binder
- Report
- Story Packet

#### Table

Replace with:

- Assignment Board
- Whiteboard
- Rundown Board
- Planning Wall

#### Notification

Replace with:

- LED Ticker
- Intercom Alert
- Sticky Note
- Monitor Alert
- Desk Message

#### Modal Window

Replace with:

- Folder Opening
- Clipboard
- Notebook
- Pull-out Drawer
- Side Workspace

#### Toolbar

Replace with:

- Broadcast Console
- Equipment Controls
- Control Panel
- Editing Console

#### Search Bar

Replace with:

- Search Terminal
- Research Terminal
- Library Catalog
- Source Finder

#### Tabs

Replace with:

- File Tabs
- Folder Dividers
- Binder Sections
- Notebook Tabs

#### Progress Bar

Replace with:

- Production Timeline
- Status Strip
- Broadcast Progress
- Assembly Tracker

#### Chat Window

Replace with:

- AI Booth
- AI Office
- AI Terminal
- Producer Assistant Station

### Environmental Consistency Rule

The same environmental object should behave consistently across Producer.

Example:

- A Story Folder always opens like a Story Folder.
- A Broadcast Monitor always behaves like a Broadcast Monitor.
- A Whiteboard always supports planning.

Changing environments should never require relearning familiar objects.

### Environmental Authenticity Rule

Every asset should feel appropriate to its environment.

Example:

The News Production profile should use:

- Monitors
- Whiteboards
- Story Folders
- Broadcast Consoles

The World Text Library should instead use:

- Bookshelves
- Reading Tables
- Manuscript Cases
- Archive Cabinets

Different environments may use different assets while still following PEAL standards.

### Acceptance Tests

This section is complete only when:

- ✓ All PEAL assets belong to a defined category.
- ✓ Generic UI components have clear environmental replacements.
- ✓ Navigation follows architectural design principles.
- ✓ Storage, planning, display, and control assets are clearly separated.
- ✓ Environmental assets remain reusable.
- ✓ Different Production Profiles can share PEAL assets while maintaining unique identities.
- ✓ Producer begins replacing web metaphors with environmental metaphors.

### Final System Rule

Producer should never default to generic interface components when a functional environmental asset can communicate the same purpose more naturally.

Every object should help reinforce the illusion that the producer is working inside a real creative environment.

PEAL establishes the vocabulary of those environments.
